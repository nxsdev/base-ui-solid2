- Direction Provider
- mergeProps
- useRender
- unstable-use-media-query

## Utilities that need a fresh review

- Floating UI integration
- Provider helpers that depend on React-only patterns
- Any utility whose old Solid implementation depends on Solid 1 context or effect timing
